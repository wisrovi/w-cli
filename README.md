## 🚀 Comenzar

Cada librería puede instalarse de forma independiente:

```bash
pip install wpipe
pip install wsqlite
pip install wkafka
# ... y más
```

O instala varias de una vez:

```bash
pip install wpipe wsqlite wkafka wpostgresql wauth
```
